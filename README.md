# 교실 배치 돌리기

학교 건물·층·교실 구조를 맞추고(1단계), 다음 학년도 교실 배치를 섞어 현재와 비교하는(2단계) 웹 도구입니다.

- 설치나 로그인 없이 링크로 바로 사용
- 고친 내용은 각자 브라우저에 자동 저장(다른 사람과 공유되지 않음)
- 같은 학년 같은 층, 붙어 있는 교실, 저학년 아래층 등 섞기 규칙
- 학급·특별실 고정, 되돌리기, 결과 복사

## 사용 팁
- 다른 기기나 다른 브라우저에서 열면 처음 배치부터 시작합니다.
- 브라우저 방문 기록·사이트 데이터를 지우면 저장 내용도 지워집니다. 결과는 '결과 복사'나 화면 캡처로 따로 남겨 두세요.
